# Project Log: Fine-tuning smolVLA on Red Block Dataset
**Date:** 2026-02-15

## Objective
The goal for today was to prepare and launch the fine-tuning of the `lerobot/smolvla_base` model on the `ThavT/red_block_in_tape` dataset (25 episodes).

## Accomplishments

### 1. Dataset Research & Inspection
- **Verified Dataset Features**: Confirmed the dataset uses `observation.images.cam_0` and `observation.images.cam_1` for video feeds and contains `observation.state` (6-dim) and `action` (6-dim).
- **Instruction Mapping**: Confirmed that while `observation.instruction` is not a per-frame feature, the `LeRobotDataset` automatically maps the `task_index` to the `"task"` string (e.g., "red_block_in_tape") which the `smolVLA` processor uses as the language prompt.

### 2. Custom Utility Scripting
Created a set of tools to make dataset inspection easier for the team:
- **`scripts/download_and_inspect.py`**: Downloads specific episodes and metadata from Hugging Face Hub without cloning the whole repo.
- **`scripts/explore_parquet.py`**: Provides a quick terminal preview of any LeRobot Parquet file (Schema, Rows, First few rows).
- **`scripts/parquet_to_csv.py`**: Converts technical Parquet data into a human-readable CSV spreadsheets (handles complex array types) for easier manual browsing.
- **Documentation**: Created a `scripts/HowTo/` folder containing markdown guides for each new script.

### 3. Training Preparation & Blockers Resolved
- **Issue: Feature Mismatch**: The base `smolVLA` configuration expects 3 cameras (`camera1`, `camera2`, `camera3`), but the dataset has 2 (`cam_0`, `cam_1`).
- **Issue: Video Backend**: The default `torchcodec` backend failed due to missing system FFmpeg libraries.
- **Solution**: Created `train_overrides.json` to:
    - Map `cam_0 -> camera1` and `cam_1 -> camera2`.
    - Explicitly set `input_features` to only include the 2 available cameras and the 6-dim state.
    - Switch the video backend to `pyav` for stability.

### 4. Status
- Verified that the training initializes correctly, loads the 100M learnable parameters, and enters the training loop on the local GPU (GeForce RTX 2080).

## Training Command
```bash
PYTHONPATH=src .venv/bin/python src/lerobot/scripts/lerobot_train.py --config_path train_overrides.json
```
