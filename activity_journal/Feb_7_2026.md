# Activity Journal: February 7, 2026

## Project: 1-DoF Finger Robot Setup with LeRobot

**Goal:** Configure a single-servo robot ("Finger") with a camera for future AI training (SmolVLA).

### 1. Hardware Initialization
- **Identified Hardware:**
    - **Microcontroller:** Waveshare Driver Board (ESP32-S3 based).
    - **Servo:** Feetech STS3215M (ID: 1).
    - **Camera:** USB Webcam (Index: 0).
    - **Power:** 7.4V LiPo Battery.
- **Port Detection:** Successfully identified `/dev/ttyACM0` as the communication port.
- **Permissions:** Added user to `dialout` group and applied `chmod 666` to fix permission errors.

### 2. Debugging "Input Voltage Error"
- **Issue:** Servo was throwing `[RxPacketError] Input voltage error!` despite being powered by a fully charged LiPo (8.4V).
- **Diagnosis:**
    - Wrote `test_motor.py` to read raw registers.
    - Discovered `Present_Voltage` was ~84 (8.4V), but `Max_Voltage_Limit` (Address 14) was set to 80 (8.0V).
- **Fix:**
    - Created `fix_motor.py` to unlock EPROM and update `Max_Voltage_Limit` to 85 (8.5V).
    - Verified the error cleared and motor communication was healthy.

### 3. Software Implementation
- **Repository Setup:** Forked and cloned `huggingface/lerobot`. Created `fingersetup` branch.
- **Robot Configuration:**
    - Created `lerobot/src/lerobot/configs/robot/finger_setup.yaml` defining the robot type, motors, and camera.
    - Updated `lerobot/robots/utils.py` to register `finger_setup` type.
- **Robot Class Implementation:**
    - Implemented `FingerRobot` class in `lerobot/src/lerobot/robots/finger/finger_robot.py`.
    - Inherited from `Robot` (base class) rather than `ManipulatorRobot`.
    - Integrated `FeetechMotorsBus` for communication.

### 4. Control Mode Decision
- **Initial Plan:** Position Control (Angle-based).
- **Revised Plan:** **Velocity Control (Speed-based)**.
    - **Reasoning:** The robot is a "spinning finger" with no mechanical stops and potentially infinite rotation. User prefers controlling direction (CW/CCW) and stopping.
- **Implementation Changes:**
    - Updated `FingerRobot` to set `Operating_Mode` to **1 (Velocity Mode)** on connection.
    - Rewrote `send_action` to interpret inputs as velocity commands (-100 to 100).
    - Handled Feetech's specific Sign-Magnitude encoding (Bit 15 for direction) automatically via the library.
    - Implemented safety clamp for Max Speed (Limit: 200 steps/s).

### 5. Keyboard Teleoperation & Data Collection
- **Implementation:**
    - Created `teleop_keyboard.py` to allow real-time control via keyboard ('Q' for CCW, 'P' for CW).
    - Added command-line arguments to adjust speed dynamically (e.g., `--speed 150`).
    - Integrated a **data recording system** into the teleop script:
        - Toggle recording with 'R'.
        - Saves camera frames as `*.jpg`.
        - Records timestamped motor actions and state observations to `data.csv`.
- **Testing:**
    - Verified smooth control at speed 150 and speed 200.
    - Successfully generated the first test dataset at `data/test_dataset/20260207_181036`.

### 6. Status Summary (End of Feb 7)
- **Robot State:** Online, healthy, and configured for Velocity control.
- **Port:** `/dev/ttyACM0` (Permanently set permissions needed or persistent udev rule next time).
- **Data Collection:** Ready for large-scale demonstration gathering.
